# Veterinaria Turnos

Sistema backend para la gestión de servicios de una veterinaria.

## Descripción

Este proyecto permite administrar los servicios disponibles de una veterinaria mediante un `ServiceManager`.

Actualmente se incluyen como servicios iniciales:

- Control
- Consulta

Cada servicio contiene:

- id
- name
- description
- duration
- price
- category
- available
